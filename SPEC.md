# Personal Branding Website - Yuvraj Pondkule

## Project Overview
- **Project Name**: AI Trainer Personal Branding Website
- **Type**: Single-page professional portfolio website
- **Core Functionality**: Showcase AI training expertise, achievements, sessions, experience, and enable client enquiries
- **Target Users**: College students, faculties, scholars, and potential corporate clients seeking AI training

## Domain
- **Domain**: yuvrajpondkule.com

---

## UI/UX Specification

### Layout Structure
- **Navigation**: Fixed top navbar with smooth scroll links
- **Sections**: Full-width sections with max-width container (1200px)
- **Responsive Breakpoints**:
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px

### Visual Design

#### Color Palette
- **Primary**: #1a1a2e (Deep Navy) - Main background
- **Secondary**: #16213e (Dark Blue) - Section backgrounds
- **Accent**: #e94560 (Coral Red) - Buttons, highlights
- **Accent Secondary**: #0f3460 (Royal Blue) - Cards, containers
- **Text Primary**: #ffffff (White)
- **Text Secondary**: #a0a0a0 (Light Gray)
- **Gradient**: linear-gradient(135deg, #1a1a2e 0%, #16213e 100%)

#### Typography
- **Headings**: 'Playfair Display', serif - Elegant, professional
- **Body**: 'Poppins', sans-serif - Clean, modern
- **Hero Title**: 4rem (desktop), 2.5rem (mobile)
- **Section Titles**: 2.5rem (desktop), 1.8rem (mobile)
- **Body Text**: 1rem with line-height 1.7

#### Spacing System
- **Section Padding**: 100px vertical (desktop), 60px (mobile)
- **Container Padding**: 20px horizontal
- **Card Padding**: 30px
- **Gap Between Elements**: 20px standard

#### Visual Effects
- **Box Shadows**: 0 10px 30px rgba(0, 0, 0, 0.3)
- **Hover Effects**: Transform scale(1.02), box-shadow increase
- **Transitions**: All 0.3s ease
- **Background Patterns**: Subtle geometric shapes

## Sections Specification

### 1. Navigation (Fixed)
- Logo: Yuvraj Pondkule
- Links: Home, About, Achievements, Sessions, Experience, Projects, Gallery, Testimonials, Contact
- Mobile hamburger menu

### 2. Hero Section
- Full viewport height
- Background: Gradient with subtle animated particles/shapes
- Content:
  - Name: Yuvraj Pondkule
  - Title: AI Trainer & Educator
  - Tagline: Empowering the next generation of AI professionals
  - CTA Buttons: "View My Work" | "Get In Touch"
- Social Icons: LinkedIn, Instagram, Facebook, GitHub

### 3. About Section
- Two-column layout (image + text)
- Profile photo placeholder
- Bio text: Teaching philosophy, global reach
- Educational background cards
- Stats: Students trained, Sessions conducted, Countries reached

### 4. Achievements Section
- Grid of achievement cards (3 columns)
- Types: Certifications, Awards, Milestones
- Each card: Icon, Title, Description, Date

### 5. Sessions Section
- Timeline-style layout
- Session cards: Title, Institution, Date, Topic, Participants count
- Categories: Workshops, Webinars, Corporate Training

### 6. Experience Section
- Timeline layout
- Entries: Role, Organization, Duration, Description
- Key responsibilities and accomplishments

### 7. Projects Section
- Grid of project cards (3 columns)
- Each: Title, Description, Tech stack, Links
- Filterable by category

### 8. Gallery/Photos Section
- Masonry grid layout
- Lightbox on click
- Categories: Training Sessions, Events, Conferences

### 9. Clients Section
- Logo grid of organizations
- Client testimonials quotes

### 10. Testimonials Section
- Carousel/slider
- Avatar, Name, Role, Institution, Quote

### 11. Contact Section
- Two columns: Form + Info
- Form fields: Name, Email, Subject, Message
- Coffee grab section: "Grab a Coffee" CTA
- Contact info: Email, Location
- Social links: Same as hero

### 12. Footer
- Copyright
- Quick links
- Social icons

## Functionality Specification

### Core Features
- Smooth scroll navigation
- Mobile responsive menu
- Image lightbox for gallery
- Form validation (client-side)
- Animated counter for stats
- Scroll-triggered animations

### User Interactions
- Navbar link clicks → Smooth scroll to section
- Gallery image click → Lightbox modal
- Form submit → Validation + success message
- Social icon clicks → External links open in new tab

### Data Handling
- Contact form: Placeholder for backend integration
- All data stored locally for demo
